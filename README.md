# 🎨 ThemeVault

**Uma biblioteca dedicada à personalização visual de aplicações, sistemas e ambientes digitais.**

O **ThemeVault** é um repositório criado para reunir, organizar e preservar temas, modificações visuais, configurações e recursos de personalização para diferentes plataformas e softwares.

## 📦 Categorias

- 🎮 **Discord:** BetterDiscord, Vencord, temas CSS e personalizações de interface.
- 🎵 **Spotify:** Spicetify, temas, paletas de cores e modificações visuais.
- 🐧 **Linux:** GTK, QT, ícones, cursores e ambientes gráficos.
- 🪟 **Windows:** Temas, ícones, cursores e personalizações do sistema.
- 🌐 **Navegadores:** Temas, extensões visuais e CSS personalizado.
- 🖥️ **Hyprland:** Configurações, animações, efeitos, transparências e decorações.
- 🖼️ **Recursos gráficos:** Wallpapers, texturas, fontes e elementos visuais.
- 🎨 **Paletas:** Combinações de cores, códigos HEX e referências estéticas.

## ✨ Características

- Organização por plataforma e categoria.
- Arquivos originais e versões modificadas.
- Pré-visualizações dos temas.
- Instruções de instalação e configuração.
- Registro de dependências e compatibilidade.
- Preservação de créditos e fontes originais.

## 🎯 Propósito

Centralizar projetos de personalização em um único lugar, facilitando o acesso, a reutilização, a manutenção e o desenvolvimento de novas identidades visuais.

## 📜 Créditos

Os créditos dos criadores originais serão mantidos sempre que aplicável. Modificações e criações próprias serão identificadas, respeitando as licenças e condições de distribuição de cada projeto.
